# Reference Applications

Reference applications run on top of the Edge Node Infrastructure software platform, which
provides the drivers and runtimes for Intel® GPU and NPU acceleration. Set up the platform
first, as described in [Infrastructure Setup](./infrastructure-setup.md), and then deploy
one or more of the following applications:

- [Handheld Multi-Modal Application](./multi-modal/index.md) — a multi-modal AI operator console
  that combines live camera analytics, evidence search, mission documents, rule-based alerts,
  and voice interaction in a single browser UI. All inference runs locally on the device.
- [AI Playground](./ai-playground.md) — an optional open source generative AI application
  suite for offline AI chat, code assistance, document search, image analysis, and image and
  video generation.
