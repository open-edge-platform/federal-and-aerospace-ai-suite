Choose how to set up the Uncrewed Aerial Vehicle (UAV) Blueprint:

- [Installation on Ubuntu](./installation-on-ubuntu.md): install the UAV Vision Analytics application on an
  existing Ubuntu 24.04 system with the OEP CLI Installer. To view the cameras on a ground station, follow
  [Installation of the UAV Ground Station on Ubuntu](./uav-ground-station/installation-on-ubuntu.md).
- [Custom Image](./custom-image.md): build a customized Ubuntu image for deployment at scale.
