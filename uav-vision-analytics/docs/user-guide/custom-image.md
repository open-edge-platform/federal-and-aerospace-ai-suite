# Custom Image

This documentation covers how to build a customized Ubuntu image that allows deployment at scale. It is
different from [Installation on Ubuntu](./installation-on-ubuntu.md), which uses a default or existing Ubuntu
operating system.

It needs an additional system, called the `Developer system`, which is covered in
[System Requirements](./get-started/system-requirements.md).
